# windows-forms
## Главное меню
Главное меню предназначено для объединения всех заданий в одном окне, оно обеспечивает навигацию между ними. При запуске программы открывается главное окно, содержащая кнопки для выбора заданий. При нажатии на кнопку открывается задание.
<img width="548" height="384" alt="image" src="https://github.com/user-attachments/assets/e29eb1e5-878a-43a2-b34c-b53f1cc79d33" />
## Игра угадай число
Программа генерирует случайное число, которое пользователь должен угадать.
При запуске пользователь видит текстовое поле, под ним находится счетчик попыток, кнопки "Угадать" и "Заново". Справа от кнопки можно увидеть подсказки.
<img width="548" height="384" alt="image" src="https://github.com/user-attachments/assets/0d83129d-a8d5-4751-8a1e-1318bbff649a" />

Пользователь вводит предполагаемое число в текстовое поле и нажимает кнопку "Угадать".
<img width="548" height="384" alt="image" src="https://github.com/user-attachments/assets/8dc70b65-2154-4444-a95d-9e66e9c3e807" />

После проверки введенного числа программа сообщается результат. Если число не угадано, пользователь получает подсказку.
<img width="548" height="384" alt="image" src="https://github.com/user-attachments/assets/1baa84f3-9b6e-4185-b937-54a2175ca0aa" />

Если же число угадано, то появляется сообщение о завершении игры. Также на сообщении можно увидеть количество попыток.
<img width="548" height="384" alt="image" src="https://github.com/user-attachments/assets/88dbc174-3e1f-42e4-a9a8-bd1d9b36cbc3" />
## Случайный цвет
При запуске открывается окно, с кнопкой "Случайный цвет" в центре.
<img width="548" height="384" alt="image" src="https://github.com/user-attachments/assets/b47b282d-749e-4a3e-a642-e69ac681657f" />

При нажатии на кнопку программа генерирует три случайных значения r, g и b. На основании этих значений появляется новый цвет фона.

<img width="548" height="384" alt="image" src="https://github.com/user-attachments/assets/fd69ce32-2cf6-47b9-9e8a-fe327c0bc821" />

## Отображение текста
Программа предназначена для ввода текста и его отображения в отдельном окне. При запуске пользователь видит текстовое поле и под ним кнопка "Отобразить".

<img width="548" height="384" alt="image" src="https://github.com/user-attachments/assets/943f8545-b535-43c8-992f-f7e0c5ae6a93" />

Пользователь вводит текст в текстовое поле и нажимает на кнопку. Программа считывает содержимое поле и отображает введенный текст в отдельном окне.

<img width="548" height="384" alt="image" src="https://github.com/user-attachments/assets/3573a718-8b83-4385-a8e8-4777d2f718f7" />

## Блокировка и разблокировка.
Программа предназначена для управления ввода текста в текстовое поле. При запуске пользователь видит текстовое поле и под ним кнопки "Блокировать" и "Разблокировать".

<img width="548" height="384" alt="image" src="https://github.com/user-attachments/assets/7a8361ea-29d1-4e88-84c6-37379631bddc" />

При нажатии на кнопку "Блокировать", текстовое поле становится светло серым цветом и программа не дает в него написать текст, поле становится не активным.

<img width="548" height="384" alt="image" src="https://github.com/user-attachments/assets/ba36ed8a-4bb3-4341-8ae8-d4a697eb8ffb" />

При нажатии на "Разблокировать" программа делает поле активным и в него можно написать текст.

<img width="548" height="384" alt="image" src="https://github.com/user-attachments/assets/4f0f4f05-43bb-46aa-9480-e45bb38666cb" />

## Канкулятор
Калькулятор предназначен для выполнения арифметических операций, таких как сложение, вычитание, умножение и деление. Также он должен предусматривать ошибки и деление на 0.
### 1 вариант
При запуске пользователь видит 4 текстовых поля. 1 для ввода первого числа, 2 для ввода операции, 3 для ввода второго числа и 4 для вывода результата. Внизу находится кнопка "Расчитать."

<img width="548" height="384" alt="image" src="https://github.com/user-attachments/assets/4c179ec5-5297-42d7-a5cb-a0310bccb1d0" />

Пользователь вводит числа и арифметическую операцию.

<img width="548" height="384" alt="image" src="https://github.com/user-attachments/assets/f4f25f9d-27a2-4134-b771-5f759b76e176" />

После он нажимает кнопку и в последнем текстовом поле появтляется ответ.

<img width="548" height="384" alt="image" src="https://github.com/user-attachments/assets/90280f48-aae6-47b7-a71c-04d024f006ea" />

При делении на 0 программа выдаст ошибку.

<img width="548" height="384" alt="image" src="https://github.com/user-attachments/assets/75c12b45-64a5-444d-b267-41ae9eeda3f9" />

### 2 вариант
При запуске программы пользователь видит текстовое поле, под ним кнопки с числами от 1 до 9, с арифметическими действиями и кнопки "Стереть" и "=."

<img width="548" height="384" alt="image" src="https://github.com/user-attachments/assets/18a213f0-f3cc-416f-aeb1-065b8848c5e9" />

Пользователь вводит числа и действия с помощью кнопок.

<img width="548" height="384" alt="image" src="https://github.com/user-attachments/assets/07c18f61-facb-416a-aab4-f0ed7d0ff931" />

При нажатии на кнопку "Стереть" поле полностью очистится.
При нажатии на кнопку "=" программа выведет результат.

<img width="548" height="384" alt="image" src="https://github.com/user-attachments/assets/f8110c73-eec7-44a3-8eaf-abd65657d3e6" />

При делении на 0 программа выдаст ошибку.
