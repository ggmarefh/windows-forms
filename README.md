# windows-forms
## Главное меню
Главное меню предназначено для объединения всех заданий в одном окне, оно обеспечивает навигацию между ними. При запуске программы открывается главное окно, содержащая кнопки для выбора заданий. При нажатии на кнопку открывается задание.
<img width="548" height="384" alt="image" src="https://github.com/user-attachments/assets/e29eb1e5-878a-43a2-b34c-b53f1cc79d33" />
## Игра угадай число
Программа генерирует случайное число, которое пользователь должен угадать.
При запуске пользователь видит текстовое поле, под ним находится счетчик попыток, кнопки "Угадать" и "Заново". Справа от кнопки можно увидеть подсказки.
<img width="548" height="384" alt="image" src="https://github.com/user-attachments/assets/0d83129d-a8d5-4751-8a1e-1318bbff649a" />

Пользователь вводит предполагаемое число в текстовое поле и нажимает кнопку "Угадать".
<img width="548" height="384" alt="image" src="https://github.com/user-attachments/assets/8dc70b65-2154-4444-a95d-9e66e9c3e807" />

После проверки введенного числа программа сообщается результат. Если число не угадано, пользователь получает подсказку.
<img width="548" height="384" alt="image" src="https://github.com/user-attachments/assets/1baa84f3-9b6e-4185-b937-54a2175ca0aa" />

Если же число угадано, то появляется сообщение о завершении игры. Также на сообщении можно увидеть количество попыток.
<img width="548" height="384" alt="image" src="https://github.com/user-attachments/assets/88dbc174-3e1f-42e4-a9a8-bd1d9b36cbc3" />
## Случайный цвет
При запуске открывается окно, с кнопкой "Случайный цвет" в центре.
<img width="548" height="384" alt="image" src="https://github.com/user-attachments/assets/b47b282d-749e-4a3e-a642-e69ac681657f" />

При нажатии на кнопку программа генерирует три случайных значения r, g и b. На основании этих значений появляется новый цвет фона.

<img width="548" height="384" alt="image" src="https://github.com/user-attachments/assets/fd69ce32-2cf6-47b9-9e8a-fe327c0bc821" />

## Отображение текста
Программа предназначена для ввода текста и его отображения в отдельном окне. При запуске пользователь видит текстовое поле и под ним кнопка "Отобразить".
<img width="548" height="384" alt="image" src="https://github.com/user-attachments/assets/943f8545-b535-43c8-992f-f7e0c5ae6a93" />

Пользователь вводит текст в текстовое поле и нажимает на кнопку. Программа считывает содержимое поле и отображает введенный текст в отдельном окне.
<img width="548" height="384" alt="image" src="https://github.com/user-attachments/assets/3573a718-8b83-4385-a8e8-4777d2f718f7" />

## Изменение текста на кнопках
Программа предназначена для изменения текста на кнопках. При запуске пользователь видит текстовое поле и под ним 3 кнопки.
<img width="548" height="384" alt="image" src="https://github.com/user-attachments/assets/9b501205-efb4-49e9-a401-530f05577439" />

Пользователь пишет свой текст в поле и при нажатии на любую кнопку, введенный текст появится на ней. 
<img width="548" height="384" alt="image" src="https://github.com/user-attachments/assets/7a5c94f3-3fdc-470a-8c87-30df52f36e49" />
